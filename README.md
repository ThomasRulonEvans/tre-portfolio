# Thomas Evans Portfolio

Single-page portfolio built with Vite, React, TypeScript, and Mantine.

**Live site:** https://thomasrulonevans.github.io/tre-portfolio/

## Run locally

```powershell
cd C:\Dev\tre-portfolio
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```powershell
npm run build
npm run preview
```

## GitHub Pages

Pushes to `main` build the site and publish it to the `gh-pages` branch.

**One-time repo setup** (required or you’ll see a blank page):
1. Open **Settings → Pages**
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: **gh-pages** / **/(root)** → Save

Live site: https://thomasrulonevans.github.io/tre-portfolio/
